# COC 部落战数据 Bot — 决策记录

## 已确定

- **目标**：国际服 CoC 部落战数据自动化，最终形态为 QQ 群 bot。理由：用户选择转国际服再自建；国服无官方公开 API，自建不划算。
- **范围**：1–3 个固定部落。理由：官方 API 限流、token 绑定 IP；公共服务成本高。
- **优先级**：先做 MVP，绑定用户后置。理由：绑定涉及身份映射/验证，第一版非必需。
- **部署**：先本地跑通，再上 VPS。理由：降低初期成本，先验证 API 与 bot 链路。
- **QQ 路线**：NapCat + NoneBot2（OneBot v11）。理由：免费、灵活；需小号，接受风控风险。
- **数据层**：MVP 用标准库 urllib + sqlite3（零依赖）；clashy.py 作为后续可选替换。理由：先降低依赖和安装成本，当前 API 端点已够用。
- **统计口径（默认，已确认）**：三星率 = 三星进攻数 / 总进攻数；摧毁率 = 平均每次进攻摧毁百分比；时间窗 = 当前战争 + 接入后积累的历史；区分常规战/CWL；样本 < 10 次标注“样本少”。
- **本地试点**：先本地跑通，接受 token 因家宽 IP 变化后重签；若家宽无公网 IP 或 IP 频繁变化，改为直接上 VPS。
- **决策记录**：本文件。

## 已知风险/事实

- 官方 API 只覆盖国际服；国服数据不互通。
- warlog 无成员逐次进攻，成员历史只能从接入后积累。
- 普通 token 无 uncached 权限，实时有缓存延迟。
- 战争日志私密时当前战争可能拿不到（PrivateWarLog）。
- 官方 API 限流；coc.py 默认 10 req/token/s，滥用可能封 IP。
- Supercell token 绑定公网 IP；家宽 IP 变化会导致 403，长期需固定 IP/VPS。
- NapCat 协议端有 QQ 风控/封号风险。
- Pi 与 PC 不同网络：现有 token 不能直接用；Pi 公网 IP 变化会 403。
- NoneBot2 依赖装在项目 Python 运行时，不在项目目录；换机器需重装。
- 工作目录沙箱 ACL 已于 2026-11-02 修复；如再出现，用 diagnose-windows-sandbox-acl 排查。
